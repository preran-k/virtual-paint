# Virtual Painter

A real-time virtual painting application developed using Python, OpenCV, and MediaPipe. The project enables users to draw on a digital canvas using hand gestures detected through a webcam, eliminating the need for a mouse, stylus, or touch input.

## Overview

The application uses MediaPipe's hand landmark detection to track hand movements in real time. Different finger gestures are interpreted as commands for drawing, selecting colors, and erasing, providing an intuitive and interactive drawing experience.

## Features

- Real-time hand tracking
- Gesture-based drawing
- Color selection using hand gestures
- Eraser tool
- Live webcam-based interaction
- Smooth canvas rendering

## Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

### Controls

**Selection Mode**

- Raise the index and middle fingers.
- Move the hand over the toolbar to select a color or the eraser.

**Drawing Mode**

- Raise only the index finger.
- Move the finger to draw on the canvas.
